# Orbit v1.5.7 更新内容

## 2026-10-17 修复补发

- 优化 Android、Windows 背景页面切换的流畅度，减少有背景与无背景页面互切时的卡顿；相同背景复用媒体实例，保持 GIF、视频播放进度。
- 修复开启背景时二级页面在过渡中显示主题底色、动画结束后才出现背景的闪烁，保留原有位移、缩放和淡出效果。
- 修复 Windows 开启背景时，上一级页面未随动画淡出、而在动画结束后突然消失的问题；返回时平滑淡入，减少页面内容叠影。
- 修复 Android 已登录「账号与同步」页面滚动后返回时，列表先闪回顶部的问题。
- 调整 Windows 背景编辑面板的按钮及分组间距，缩放控件整组换行，改善宽窄窗口、中文和放大字体下的排布。
- 保持现有背景设置及备份格式兼容，无需迁移数据。已安装原 v1.5.7 的用户可下载本次附件手动覆盖安装／替换；版本与内部构建号不变，应用内更新不会将其识别为更高版本。

## 背景保存与编辑

- 修复背景保存和退出流程：直接保存当前编辑，成功后提示并退出；失败保留草稿，可重新尝试，退出时可保存或放弃。
- 编辑器改为「选择一个页面 → 区域与构图 → 效果调整 → 保存」。两步均支持直接点击预览区域、缩放和拖动；预览不会执行课程、导入或设置业务操作。
- 手机提供可展开控制面板，Windows 宽窗口使用侧栏；效果步骤优先显示模糊、暗化和底板透明度。
- 修复窗口布局切换时失效的区域引用，并改善大字体、窄窗口和空课表提示的显示。

## 跟随课表与可读性

- 其他页面可持续跟随课表的素材、构图、播放进度、效果，以及标题栏和主导航背景开关。
- 跟随页面的共享参数只读，避免反向修改课表；关闭跟随后保留当前效果并独立编辑。其他区域、底板透明度与文字保护独立设置。
- 新增整张背景模糊，保留图片边缘的模糊填补；暗化上限提高至90%。
- 暗化低于30%时可自动添加柔和文字阴影，随暗化提高逐渐减弱，可按页面关闭；弹窗保持原文字样式。
- 图片、GIF 和静音视频继续支持，模糊复用现有媒体，不增加播放器实例。

## Android 安装包与更新

- 新增 ARM64（arm64-v8a）、ARMv7（armeabi-v7a）和 x86_64 专用 APK，同时保留通用 APK。
- 通用包沿用 `orbit-v1.5.7-android.apk`，专用包命名为 `orbit-v1.5.7-<ABI>.apk`，保证 GitHub 返回的首个 APK 仍为通用包，兼容旧客户端。
- 多数现代 Android 手机可选择 ARM64 包，显著减少下载体积；通用包保留完整架构兼容能力。
- 应用内更新按设备支持的架构优先匹配，并按每个安装包的文件名、大小和 SHA-256 校验；旧清单或未知架构回退通用包。
- 所有 APK 使用相同内部版本号和现有正式签名证书，支持在专用包与通用包之间正常升级并保留数据。
- Windows 提供完整 x64 ZIP，解压后运行 orbit.exe，保留同目录 data/ 和 DLL。

## 版本与验证范围

- 版本1.5.7，内部构建号29。Android、Windows 使用现有正式 CloudBase 编译配置。
- 背景修订及本次修复已通过静态分析、676项 Flutter 自动化测试（1项跳过）；发布清单由最终附件重新生成，并核验版本、签名、架构和包散列。
- Windows 原生 profile 已验证静态图、GIF、视频背景下的真实「课表 → 搜索课程」进入与返回，以及主导航和已登录账号页滚动返回；组件测试覆盖嵌套页面与动画中途返回。
- Windows 原生视频后端已验证静音解码、循环、暂停和恢复。
- Android 真机锁屏、后台恢复、真实触控与普通／强提醒并发，以及 Windows 托盘和实际视频纹理恢复仍需设备验收。

正式发布构建核验：四个APK均为1.5.7（29），沿用现有正式签名，专用包仅含目标ABI。Windows EXE版本1.5.7+29，ZIP的35个文件与Release输出逐文件匹配，正式模式静音视频检查通过。更新清单由最终安装包的实际大小与SHA-256生成。

本次附件体积（十进制）：ARM64 38.98MB，ARMv7 36.59MB，x86_64 44.00MB，通用APK 116.84MB，Windows ZIP 36.59MB。ARM64包相较v1.5.6通用包减少约66.6%的下载体积。
