# Orbit v1.6.0 更新内容

发布日期：2026-10-17；内部构建号：30。

## 启动与课表动画

- 新增快速启动动画：主题色背景、圆形图标与圆润 Orbit 字标；可在设置上传、裁剪及重置启动图标，提供完整预览。
- 课表界面由左上至右下淡入，网格逐步延展，底部导航按钮依次浮现并轻微回弹；宽屏侧栏同步适配。
- 课程卡片及可见的当前时间线按日期从上下方均衡交错进入，提供从边缘或附近进入两种模式。
- 仅在新进程启动播放，支持系统减少动画设置；交互及通知入口可结束动画，避免延迟操作。
- Orbit 字标采用 OFL 许可的 Nunito 字体，随包附许可文件。
- 修复 Android 12+ 原生启动屏引用方形图标的问题，改用带透明安全边距的圆形资源；统一启动背景并预载图片，改善原生启动屏到应用首帧的衔接。桌面进入启动屏前的系统图标缩放仍由系统控制。

## 独立字体自定义

- 在“设置 → 外观 → 字体”分别设置应用界面字体和开屏字标字体，启动动画设置页也提供字标字体入口。界面默认保留平台字体行为，字标默认 Nunito，两套选择互不影响。
- 离线内置资源圆体、jf open 粉圆和荆南麦圆三款圆润中文字体，附版权与 SIL OFL 许可，并登记到应用许可页。
- 支持导入 TTF、OTF 及有效的可变字体，单文件最多 50MiB；提供简繁中文、英文、数字与课程卡片预览，确认后应用。字体库支持去重、重命名和删除。
- 字体复制到应用私有目录，缺失或加载失败时安全回退；保留现有字号、字重及系统文字缩放，图标字体独立，系统通知和键盘继续使用系统自身字体。
- 完整备份升级至 v11，携带两套选择及正在使用的导入字体，按内容哈希去重；兼容 v1–10 备份，仅恢复课程时不改变字体。字体文件及选择不加入云同步。

## 回到顶部与打卡入口

- 回到顶部按钮支持居左、居中、居右、智能四种位置，默认智能；悬浮按钮与列表底部按钮共用位置，随显示设置保存、备份和同步。
- 智能模式结合触摸分布、滑动轨迹、陀螺仪与重力信息估计左右手或双手操作；加入稳定判断、切换冷却和触摸结束后换位，降低跳动。
- 传感器仅在智能模式且页面前台可见时采样；缺失传感器时退回触摸判断，无法判断或鼠标操作时居中。操作数据仅保存在内存。
- 仅从打卡提醒进入的 Android 课程详情显示“打开 WeMust 课表”，链接启动失败时打开 WeMust，并保留手动进入课表的提示与后备入口。

## 包与兼容性

- 版本号 1.6.0，内部构建号 30；沿用现有 Android 正式签名和 CloudBase 编译配置。
- 提供 Android 通用、ARM64、ARMv7、x86_64 APK 与 Windows x64 ZIP。Windows 需完整解压后运行，保留 data/ 与 DLL。
- 兼容现有本机数据及旧备份；旧设置缺失按钮位置时使用智能模式。启动图标为本设备私有设置。
- 自动验证：Flutter 全量回归 741 项通过、1 项跳过，最终字体与设置恢复相关测试 30 项通过，格式与静态检查通过。2 项发布清单测试及 4 项云端更新范围测试通过。四个 Android Release APK 的版本、正式签名、架构、字体与许可资源校验通过；Windows Release 原生自检通过，ZIP 的 45 个文件与构建输出一致。附最终包 SHA-256 清单及应用更新清单。
- 尚无 Android 真机验收；Android 12+ 深浅主题、冷／热启动及通知启动的视觉衔接、真实持机识别，以及 WeMust 在登录前后、冷启动和后台恢复时的实际页面落点仍待验证。不将 Intent 启动成功视为已到课表或完成打卡。
