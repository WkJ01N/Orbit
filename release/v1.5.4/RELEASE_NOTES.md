# Orbit v1.5.4 更新内容

## 课表选中与强提醒

- 修复课程详情关闭后选中框残留，以及翻页时相同节次卡片边框闪烁；点击空白、切换标签和开始翻页都会清除普通选中状态。
- 强提醒铃铛移至课程卡片上方，保留说明与遮挡判断，避免遮盖课程名称和时间。
- 强提醒改为课程卡片内部底色渐变；设置的课表展示新增“强提醒卡片渐变”，支持上半、整张和顶部，默认上半。
- 渐变使用实际课程配色，支持浅色、深色和手动配色；偏好进入本地保存、完整备份与课表展示分类同步。

## 批量删除

- 新增按课程、按时间段和手动选择三种方式，支持搜索、跨学期多选及可选包含归档课次。
- 按时间段删除会单独列出跨越边界的课次，由用户逐项确认是否加入删除范围。
- 手动选择支持跨周、跨日累积勾选；顶栏、系统返回、Windows Esc 和切换标签统一使用取消确认，防止丢失已选课程。
- 删除前可展开预览并取消单项，提交前重新核对课程数据；失败保留选择，防止重复提交，成功后更新课表与提醒。
- 大批量删除与撤销分段执行并保持同一数据库事务，继续使用回收站与云端删除标记。

## 版本与兼容

- 版本号更新为 1.5.4，内部构建号更新为 `+26`；应用内版本展示和同步设备版本声明保持一致。
- SQLite 数据库维持 v9，JSON 备份维持 v8；旧设置缺少渐变偏好时默认使用上半渐变，保留现有数据。

- Android APK 与 Windows x64 ZIP 使用项目现有生产同步环境配置，产物位于 `release/v1.5.4/`。
