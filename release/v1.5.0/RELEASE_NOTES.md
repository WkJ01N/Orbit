# Orbit v1.5.0 更新内容

## 账号与同步

- 正式开放邮箱账号，可注册、登录、找回密码，并在 Windows 与 Android 设备间同步课表。
- 密码需为 8–20 位且同时包含字母和数字；验证码支持在 60 秒冷却结束后重新发送。
- 注册时可选填用户名，登录后可以修改用户名和头像。
- 注册、验证码和登录窗口不会因误触外部区域而关闭，避免重复输入。
- 首次登录提供本机与云端课表合并预览；冲突课程由用户选择保留内容，退出账号默认保留本机课表。
- 新增启动、回到前台、本地修改、网络恢复四种自动同步条件，可限制为 Wi-Fi／有线网络，也可随时手动同步。
- 优化同步速度和连续修改时的请求合并；同步失败不会覆盖本机课程，可在下次事件或手动操作时重试。

## 多格式课表导入

- XLSX 支持多工作表、通用课程列表、列顺序变化、额外列，以及常见简繁中文和英文字段名；原有 13 列格式继续兼容。
- CSV 支持 UTF-8、GBK、GB18030、逗号、分号和制表符，并正确处理引号、转义及字段内换行。
- 新增星期为列、节次为行的周网格识别，支持纵向合并节次和一格多课。
- 新增可视化识别模板，可选择课程区域、映射字段、使用固定值或正则捕获组，并直接预览匹配及课程展开结果。
- 新增学期与作息方案，可保存第一周日期、总周数和每节课起止时间，支持连续周、离散周及单双周。
- 导入前显示采用的模板、方案、有效课程、重复项和具体错误位置；错误项必须修复或明确跳过。
- 识别模板支持复制、启停及 JSON 分享；完整备份升级至 v5，包含模板、学期、作息和自动同步设置，并继续读取 v1–v4 备份。

## Android 提醒可靠性

- 优化原生后台提醒，应用回到桌面、锁屏或从最近任务划掉后仍可正常通知。
- 新增默认关闭的增强提醒模式，在存在未来提醒时通过低打扰常驻通知提高后台可靠性。
- 新增提醒阶段诊断、系统闹钟状态、异常退出原因提示，以及 OriginOS 自启动、电池和最近任务设置引导。
- 一分钟测试提醒现在可以检查登记、接收和通知发布阶段。
- 修复提醒设置滑动到“权限与维护”区域时的明显卡顿。

## 界面优化

- 优化 Windows 登录和注册区域宽度，宽窗口下保持居中紧凑。
- 优化手机端英文按钮、学期与作息输入提示及节次时间编辑布局，避免文字过长导致截断或溢出。
- 补充简体中文、繁体中文和英文界面文案。

## 版本与兼容

- 版本号更新为 1.5.0（build 19）。
- 支持从现有版本直接升级并保留本机课表、设置与提醒配置。
