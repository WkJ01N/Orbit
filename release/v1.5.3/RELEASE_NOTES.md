# Orbit v1.5.3 更新内容

## 归档与接下来

- 课程课次和已完成 DDL 支持归档、隐藏、重新显示及取消归档；设置新增归档管理页面，支持搜索、分组、排序和批量操作。
- 设置的归档分组新增“归档所有已结束课程”，一次归档所有未归档的已结束课次，确认时可选择是否隐藏；进行中及未来课次保留。
- 课程和 DDL 可分别设置自动归档与延迟；取消归档后暂停自动归档，保留历史记录及原课程关联。
- “接下来”支持下拉刷新、Windows 刷新按钮和返回页面时刷新，刷新后移除已结束课次。

## 强提醒与加课

- 强提醒新增“仅第一节课”，支持课表第一节次及指定时刻前的每日最早课次，并保留自定义提醒规则优先级。
- 调试设置新增立即强提醒测试、Android 一分钟后后台测试和停止测试。
- 单节及批量加课支持搜索并选择现有课程，包含仅有归档历史的课程；新课次保留课程身份、配色及课程级提醒关联。

## 强提醒确认、同步范围与更新

- 强提醒新增限时确认：两道心算或两轮顺序点击，打开应用先暂时静音；超时或退出恢复，最多三轮，支持长按紧急停止。
- 通知引导打开答题；划掉未确认通知会重新出现。课程卡片与详情显示本机生效的强提醒标识。
- 账号设置新增同步内容、设备独立／账号统一范围及重新开启的合并预览；强提醒默认不参与同步。
- 设置新增检查更新、每日自动检查、国内镜像测速、可取消下载及官方大小／SHA-256 校验，校验后提供平台安装入口。

## 版本与兼容

- 版本号更新为 1.5.3，内部构建号更新为 `+25`。
- SQLite 数据库升级至 v9，JSON 备份升级至 v8；旧记录与旧备份补齐默认值，保留现有数据。
- 归档状态、原课程关联和节次信息进入同步；旧客户端省略新增字段时保留现有元数据。

## 发布说明

- Android APK 与 Windows x64 ZIP 使用项目现有生产同步环境配置。
- 本次重新构建的版本为 1.5.3+25，包含归档及本次强提醒、同步范围与更新功能。
- 云端同步兼容调整位于 `cloudbase/functions/`；自行部署时需同步更新云函数及新增集合权限。客户端构建不会自动部署云端代码。
