# Orbit v1.5.2 更新内容

## 跨校课表识别

- XLSX／CSV 自动识别升级为表头、实际行数据与网格结构综合评分，不再只依赖精确表头。
- 支持偏移表头、全半角及空白差异、常见字段近义词和不同列顺序，并通过日期、星期、周次、节次与时间内容校验降低误判。
- 周课表网格支持三至七个星期栏、周日起始、装饰行、空行、节次范围、纵向合并格以及一格多课。
- 只有置信度不低于 0.85、领先下一候选至少 0.15 且试解析成功时才会自动推荐；模糊结果必须由用户确认，不会静默导入。

## 可视化模板编辑器

- 模板编辑改为三步向导：在原表中标记结构与区域、为字段分配角色和提取方式、查看实时提取结果与课程预览后保存。
- 宽屏使用表格与右侧检查器，窄屏使用表格与底部检查器；支持横纵滚动、合并格提示和当前选择高亮。
- 普通模式提供原值、首个非空行、指定行、标签后的值及分隔符前后等提取方式；高级模式继续支持完整正则、捕获组和 flags。
- 配置变化后会在后台更新预览；旧模板无法还原为普通控件时自动回退到高级规则，不改变原有解析效果。

## 兼容与范围

- 模板版本继续保持为 1，仅追加可选的可视化编辑提示；旧模板、模板 JSON 分享、完整备份和多设备同步继续兼容。
- 支持从现有版本直接覆盖升级，保留本机课表、模板、设置和提醒配置。
- 本版本仅扩展本地 XLSX／CSV 导入，不包含学校教务登录、远程模板库、PDF、图片 OCR 或其他格式。
- 版本号为 1.5.2，内部构建号为 22。
