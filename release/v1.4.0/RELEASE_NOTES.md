# Orbit v1.4.0 更新内容

## 提醒与通知权限

- 新增“提醒时间自定义”页面，支持添加、编辑、复制、启停和删除多条提醒规则。
- 自定义提醒支持课程开始或结束前后、课程日期固定时刻，以及提前或延后若干天；支持秒级时间设置、重复次数和发送间隔。
- 提醒范围支持全部课程、指定课程系列和指定课次，并可按星期、日期范围及课程类型筛选；支持预览匹配课程和后续提醒时间。
- 课次选择支持按日期分组、日期跳转和连续浏览，默认定位今天，取消选择不保存更改。
- 支持自定义提醒标题和正文，提供课程信息、时间及发送次数等变量与文案预览；默认提醒模板也支持插入变量，次日汇总可分别编辑有课和无课文案。
- 优化规则编辑的时间输入、正文留白、星期显示及未保存退出提示；“放弃更改”使用红色标识。
- 新增强提醒开关及配置页面，可按课前提醒、签到提醒、次日汇总、自定义规则和课程范围设置。
- 自定义规则可选择继承设置、普通提醒或强提醒；明确指定的提醒方式优先于全局设置。
- 次日汇总仅在包含选中课程时使用强提醒，无课汇总保持普通提醒，汇总内容仍包含完整课程信息。
- Android 强提醒支持循环声音、重复震动、持续时间、系统铃声、音频导入及试听；Windows 支持系统循环提醒音和停止操作。
- 优化同时触发多个强提醒时的播放，避免声音叠加；“停止”结束当前强提醒，“已知晓”取消当前课程当前规则的后续重复提醒。
- 新增覆盖主页面和二级页面的通知权限警告，提供“去开启”和“忽略且不再提示”；忽略前需再次确认，设置中可恢复提示。
- 通知权限变化后自动刷新状态，恢复授权后重新安排提醒；忽略提示的选择仅保存在当前设备。
- Android“去开启”直接进入通知设置，精确闹钟与后台权限在对应设置项处理。
- 兼容原有提醒设置，保留已启用强提醒的原有覆盖范围，新安装默认关闭强提醒。

## 后台提醒

- 完善课程、规则及系统时间变化后的提醒更新，以及重启和后台恢复后的排程。
- 修复重复提醒、确认状态和补发记录在重新排程或重启后丢失的问题，避免重复发送或恢复已取消的提醒。
- 补发仅保留过去 24 小时内每节课每条规则最后一条未处理提醒，标明原计划时间与补发时间。
- Windows 支持完全退出后的已排程提醒，自动补充后续任务，并在后台处理停止和确认操作。
- 优化 Windows 启动和长期后台运行后恢复窗口时的卡顿。
- 移除“系统闹钟”设置入口，保留后台定时课程提醒。
- 移除后台提醒板块底部的“已在 iQOO V2408A……”设备验证说明。

## 配色与课程颜色

- 单色与多色改为互斥模式，分别保存配置，切换时恢复各自上次选择；保留原有单色效果。
- 新增“设置 → 外观 → 多色配色”二级页面，支持九种预设方案及主色、辅色、第三色独立编辑。
- 调色板支持添加、编辑、删除、排序、重置和选择主题色，拒绝重复颜色；删除调色板颜色保留已选主题色。
- 修复多色方案几乎全为青色、配色与描述不符的问题，调整彩色方案的三色搭配；中性和黑白保持低饱和与灰阶效果。
- 为各方案增加三色预览和简短说明，统一预览与实际主题的亮暗配色；自定义三色保留所选色相。
- 切换预设时恢复已保存的多色种子，保留原有自定义配置及调色板。
- 将“主题风格”改名为“课程配色”，继续独立支持统一颜色和自动分色；多色模式下自动分色使用调色板，颜色不足时自动补充。
- 修复课表与“接下来的课程”自动颜色不一致、两门课程颜色重复及恢复默认后颜色未更新的问题。
- 保留手动课程颜色和已有自动颜色；新增或删除课程不打乱其他课程颜色，调色板删除仅调整受影响课程。
- 修复快速连续修改配色时旧加载结果覆盖新选择的问题。
- 优化浅色模式下课程块、按钮、标签、边框和消息背景的配色与文字可读性。

## 设置与页面布局

- 保留设置顶部四个分类，统一分组卡片、标题间距及分隔线，整理语言、外观、课表、提醒、权限和数据操作的分组。
- 修复后台提醒顶部说明贴边，统一说明文字的内边距。
- 修复窄屏和放大字体时的标题截断、控件挤压正文、重复缩进与不合理留白；选择控件在空间不足时换行。
- 优化配色、强提醒和自定义提醒二级页面布局，调色板随字体大小调整网格，颜色操作面板支持滚动。
- 自定义提醒列表的添加入口改为右上角加号；无规则时在页面中央显示说明和“添加规则”按钮。

## 课表与交互动画

- 新增课表纵向高度缩放，支持 50%–150% 调整，与紧凑、标准、宽松密度组合使用，并保留当前浏览时刻。
- 新增课表自适应页面，可完整显示 08:00–22:00 并保留上下留白；超出时段的课程仍可滚动查看，关闭后恢复手动缩放值。
- 优化小课程块的内容显示、点击和重叠课程选择；调整窗口大小时保持浏览位置。
- 优化课表左右滑动的跟手性，新的拖动可立即接管收尾动画；改用弹簧过渡，修复连续快速滑动和反向滑动时的衔接问题。
- “接下来的课程”新增带滚动进度环的回到顶部按钮，支持浮动与页尾切换，回顶过程可被拖动或滚轮打断。
- 修复移动端变高课程列表滚动时进度环偶尔抖动的问题，滚动停止后平滑校正进度。
- 恢复同步提醒、删除课程、撤销等底部消息的淡入上移和淡出下移动画；关闭、超时和操作按钮使用连续退出效果，保留滑动移除、消息队列及撤销操作。
- 修复 Android 底部消息动画不可见的问题，避免关闭中的弹窗遮住进入动画，以及课程刷新卡顿让动画直接跳到结束。
- 优化导入页面“课表文件格式”的展开与收起动画，支持中途反向操作。
- 新增动画遵循系统减少动画设置，并完善简体中文、繁体中文、英文及无障碍支持。

## 数据与备份

- 备份新增自定义提醒规则、强提醒范围、音频、独立多色配置、调色板、课程自动颜色及课表显示设置，兼容旧备份。
- 支持提醒音频去重备份与恢复，缺失或不支持的音频回退系统默认声音并提示。
- 跨设备恢复后按恢复时间重新安排提醒，保留课程颜色与旧版显示设置的兼容性。
