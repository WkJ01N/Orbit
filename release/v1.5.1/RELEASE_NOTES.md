# Orbit v1.5.1 更新内容

## DDL 与界面修复

- 可从课表和近期页面的添加菜单新建 DDL，填写任务名称、选择现有或自定义科目及截止时间；支持编辑、删除、标记完成与重新打开。
- 课表日期显示 DDL 标记，近期页面显示待办、逾期与已完成状态。默认提前 1 天和 1 小时提醒，也可多选预设或自定义提前时长；仅安排仍在未来的提醒。
- DDL 与完成状态支持多设备同步，并纳入 JSON 备份。旧客户端不会收到无法识别的 DDL 同步记录；现有课程提醒规则保持不变。
- 修复头像保存时云端资料字段错误，上传失败时保留原头像；裁剪框在窄屏及窗口缩放后保持可见。
- 裁剪图片时改为拖动框选区域，并约束边角手柄始终位于可见范围；窗口缩放后会重置裁剪视口，避免沿用旧坐标。
- 英文课程详情页的操作按钮会按空间换行，完整显示文字，不再省略。

## 登录与多端会话

- 登录页面不再显示仅注册时需要的密码规则提示；注册页面继续保留完整规则说明。
- 使用 Orbit 自有设备会话支持 Android、Windows 等设备同时登录；无需增加 CloudBase Refresh Token 会话额度。
- 每个账号最多保留 5 台设备，第 6 台设备登录后立即淘汰最早设备；同一设备重复登录不会重复占用名额。
- 退出账号只退出当前设备并保留本机课表；会话失效时平稳回到未登录状态，普通断网不会误删登录凭证。
- 离线退出会先清除本机登录状态，并在下次联网时安全补发撤销；密码重置会撤销全部设备会话。

## 同步接口

- 资料、头像和课表同步统一改用 `orbit-api` HTTPS 接口，每次请求都会校验设备会话是否仍然有效。
- 同步请求使用 gzip 二进制 JSON，上传批次限制为 100 项和 4 MiB，完整快照改为分页获取。
- 升级后会自动将旧 CloudBase 登录状态兑换为 Orbit 设备会话，原 UID 与云端课表无需迁移。

## 个人资料与头像缓存

- 进入“账号与同步”、打开“编辑个人资料”以及应用回到前台时自动刷新账号资料，并合并同时发生的刷新请求。
- 头像以账号与云端文件 ID 为版本在本机持久缓存；文件 ID 未变化时直接读取缓存，不再重复获取下载地址或下载图片。
- 云端头像变化时自动更新缓存；下载失败继续显示原头像并在后续刷新时重试，移除头像时同步清理当前账号缓存。
- 上传新头像后直接使用本机处理结果更新预览与缓存，无需再次从云端下载。

## 头像裁切与输出

- 选择 JPG、PNG 或 WebP 图片后先进入裁切界面，确认前不会上传。
- “正方形裁切”默认开启；关闭后可自由框选，并可选择互斥的“拉伸”或透明“填充”方式输出正方形头像。
- 自动处理图片方向，最长边限制为 512 像素且不放大小图，统一输出 PNG。
- 优化手机窄屏与 Windows 宽屏下的裁切布局；取消裁切不会改变原头像。

## 版本与兼容

- 版本号保持 1.5.1，内部构建号更新为 21。
- 支持从现有版本直接升级，保留本机课表、设置与提醒配置；本次更新未更改提醒功能。
- CloudBase 最大会话数可保持 1，多端登录由 Orbit 自有设备会话提供。
