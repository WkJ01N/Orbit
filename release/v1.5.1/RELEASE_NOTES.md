# Orbit v1.5.1 更新内容

## 登录与多端会话

- 登录页面不再显示仅注册时需要的密码规则提示；注册页面继续保留完整规则说明。
- 支持 Android、Windows 等设备同时登录，服务端最多保留 5 个有效会话，第 6 个会话登录后淘汰最早会话。
- 退出账号只退出当前设备并保留本机课表；会话失效时平稳回到未登录状态，普通断网不会误删登录凭证。

## 个人资料与头像缓存

- 进入“账号与同步”、打开“编辑个人资料”以及应用回到前台时自动刷新账号资料，并合并同时发生的刷新请求。
- 头像以账号与云端文件 ID 为版本在本机持久缓存；文件 ID 未变化时直接读取缓存，不再重复获取下载地址或下载图片。
- 云端头像变化时自动更新缓存；下载失败继续显示原头像并在后续刷新时重试，移除头像时同步清理当前账号缓存。
- 上传新头像后直接使用本机处理结果更新预览与缓存，无需再次从云端下载。

## 头像裁切与输出

- 选择 JPG、PNG 或 WebP 图片后先进入裁切界面，确认前不会上传。
- “正方形裁切”默认开启；关闭后可自由框选，并可选择互斥的“拉伸”或透明“填充”方式输出正方形头像。
- 自动处理图片方向，最长边限制为 512 像素且不放大小图，统一输出 PNG。
- 优化手机窄屏与 Windows 宽屏下的裁切布局；取消裁切不会改变原头像。

## 版本与兼容

- 版本号更新为 1.5.1（build 20）。
- 支持从现有版本直接升级，保留本机课表、设置与提醒配置；本次更新未更改提醒功能。
- CloudBase 测试与生产环境均需将最大会话数配置为 5，才能完整启用多端登录。
