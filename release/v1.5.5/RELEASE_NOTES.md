# Orbit v1.5.5 更新内容

## 统计与完整备份

- 新增账号统计：实际使用天数、首次使用日期、已上课次、累计上课时长、DDL 完成总数及学完课程，支持历史回填、明细去重、账号隔离与离线同步。
- 课程删除可选择同时删除对应统计，默认保留；撤销及回收站恢复同步恢复对应统计。
- JSON v9 完整备份纳入课程、DDL、归档、回收站、统计、模板、学期、作息方案、用户设置与关联音频，兼容旧备份和分类合并／替换。

## DDL 与页面显示

- DDL 支持按日、周、月有限批量生成和复用；复用时可选择完成后是否计入统计。
- 每条 DDL 可独立启用强提醒，并逐个提前时间选择普通或强提醒；180 分钟及以内默认强提醒，手动选择优先。
- 打开 Orbit 即可关闭当前 DDL 强提醒，无需做题且不标记任务完成；支持保留、全部关闭、部分关闭和恢复后续提醒。
- 课程与 DDL 分别保存确认状态，共享声音时优先播放正在响铃的课程提醒。
- 课表保留原有日期栏布局，点击整个日期格子可展开当天 DDL，强提醒 DDL 使用粗体与铃铛标识；详情、编辑及管理面板适配三种语言和大字体。
- 设置新增隐藏接下来／导入页面的独立开关，手机底栏与桌面侧栏同步生效，直接操作仍可打开带返回按钮的页面。

## 课程与强提醒体验

- 提醒设置底部的后台设置入口统一命名为“系统后台设置”，同步更新简体、繁体与英文文案。

- 优化课程详情操作分组，删除按钮独占底部整行，采用危险色文字、图标与浅色背景；四个常规操作根据可用宽度排列。
- 修复强提醒配置卡片内边距，算术与数字点击分别支持自定义 1–10 轮，默认 2 轮。
- 新增混合模式，每轮以各 50% 概率随机使用心算或顺序数字，独立保存 1–10 轮；数字数量支持 4–25，默认 6。
- 心算支持简单、中等（默认）、困难难度，答题方式支持手动输入（默认）、三选一和六选一；题目与选项在答错、超时重试和恢复应用时保持稳定。
- 修复 5 秒紧急停止，增加长按进度、剩余秒数及反馈动画，兼容系统减少动画设置。

## 版本与兼容

- 版本号为 1.5.5，内部构建号为 `+27`；应用内展示、同步设备版本声明和平台安装包版本一致。
- SQLite 升级至 v11，JSON 备份使用 v9；旧数据补齐默认值。
- Android APK 与 Windows x64 ZIP 使用项目现有签名／同步环境配置，产物位于 `release/v1.5.5/`，附文件大小与 SHA-256 校验清单。
- 兼容云函数已先于客户端部署，保留旧客户端缺失的统计、DDL 强提醒与导航设置字段；四个函数均为 Active，线上代码与本次发布源码一致。
- Windows 实际通知历史、音频播放、独立计划任务触发及故障回退自测已通过；Android 真机声音／锁屏与 Windows 托盘、通知点击等人工交互验收仍待进行。

## 删除按钮、数字排列与 Windows 强提醒修复

- 课程详情删除按钮独占底部一整行，高度至少 48dp，保留原有删除确认、统计删除选择及撤销；常规操作适配极窄屏、窄屏和宽屏。
- 顺序数字 4–25 个按行排列，末行整体居中；混合模式同样生效，答错与刷新保持位置稳定，按钮至少 48dp。
- Windows 强提醒支持系统音／导入 MP3、M4A、WAV、声音开关及最长 10 秒试听；导入限制 5 MiB，原生解码校验失败保留旧选择。
- 后台独立播放音频，静音通知单独投递；文件或媒体播放失效回退系统音，媒体引擎不可用时采用 WinMM 系统 WAV。
- Windows 前台课程先通知并播放，再由用户点击通知、应用内入口或重新打开窗口进入答题；轮询不再自动静音或反复弹出答题。DDL 前台自动确认规则保留。
- 修复提醒工作进程、即时提醒交接和计划任务注册，异常退出一分钟后重试一次；新增实际通知权限查询、系统设置入口与提醒诊断。
- 调试成功等待对应实例的真实播放及通知历史回执；通知失败不停止音频，播放器失败不阻止通知。真实 Windows 计划任务、通知、三种格式和失败注入自测已通过。
- 版本沿用 1.5.5+27、SQLite v11 与 JSON 备份 v9，两端安装包、更新清单与 SHA-256 已重新生成。具体自测与人工验收范围见 docs/windows-strong-reminder-validation.md。
