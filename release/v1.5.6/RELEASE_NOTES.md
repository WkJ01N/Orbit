# Orbit v1.5.6 更新内容

## 页面背景与动态壁纸

- Android、Windows 支持选择图片、GIF 和静音视频作为页面背景，素材复制到应用目录并按内容散列去重。
- 课表支持标题、周选择、日期、时间刻度、课程网格和导航分区；接下来、导入、设置也可按实际页面区块独立设置。
- 在真实页面布局中预览，点击开关区域，双指缩放拖动；Windows 支持鼠标拖动、滚轮缩放、居中和重置。
- 新增底板不透明度、背景暗化、允许露边及主题底色／模糊填补选项，保留文字、图标、网格线和课程配色。
- 先配置课表，再选择其他页面并逐页预览，统一保存；支持重新编辑、上一步、保存或放弃草稿，预览不会执行课程或设置业务操作。
- 相同素材共用课表构图时，背景与播放进度在切页中保持连续；独立构图或不同素材跟随页面切换。
- 完整二级页面捕获来源背景，底部弹层和对话框保留现有底板；隐藏导航入口的页面仍可在编辑器配置。

## 播放与备份

- GIF 与视频默认循环；视频禁用音轨、字幕，音量为零，可关闭动态播放，系统减少动态效果时使用静态封面。
- 后台、锁屏、Windows 隐藏或最小化时暂停；恢复后继续。视频保留原文件，不做裁剪或转码。
- 完整备份升级至 v10，兼容 v1–v9；可选导出包含去重原始素材的 `.orbit` ZIP，默认 JSON 只包含背景描述和构图。
- 大视频采用流式文件处理，Android 使用系统文档输出流；恢复先校验文件与散列，失败回滚设置和新文件。
- 旧备份不含背景字段或仅恢复课程时保留本机背景；缺失素材可提示补选，背景配置与素材不进入云同步。

## 版本与构建

- 应用版本为 **1.5.6**，内部构建号 **28**；应用内版本、安装包版本和更新清单保持一致。
- Android 使用现有正式签名证书，保留既有数据升级路径；Android 与 Windows 使用项目现有正式 CloudBase 配置。
- 提供 Android APK、Windows x64 ZIP、`update-manifest.json` 与 `SHA256SUMS.txt`。

## 验证范围

- 背景升级已通过 Flutter 静态分析、661 项自动化测试与既有课表视觉基线；1 项需显式启用的系统通知测试跳过。
- Windows 原生媒体库实测带音轨视频的静音解码、循环、暂停及恢复。
- Android 真机锁屏、后台恢复、系统文档导出取消与普通／强提醒声音共存，以及 Windows 交互式托盘／纹理恢复仍需设备验收，自动化验证不替代这些场景。

本次发布构建核验：版本一致性及更新测试 6 项通过；APK 版本 1.5.6（28），签名证书与 v1.5.5 相同；Windows 版本 1.5.6+28，ZIP 共 35 个文件与 Release 目录逐文件校验一致，生产运行模式下的静音解码、循环和暂停／恢复测试通过。更新清单使用最终安装包的实际大小与 SHA-256 生成。
