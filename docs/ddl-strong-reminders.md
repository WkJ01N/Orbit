# DDL 强提醒与导航显示

每个 DDL 可独立启用强提醒，并逐个提前时间选择普通或强提醒。首次选中一个时间时，180 分钟及以内默认强提醒，更早默认普通；手动选择优先。单个、批量、编辑与复用采用相同配置。复用复制配置并清空后续提醒关闭记录，新任务保持未完成。

DDL 使用设置中的音频、振动和每次响铃时长，最多三次，间隔 15 秒。课程强提醒总开关、范围与做题设置不限制 DDL。原生侧在前台投递时直接确认 DDL；后台触发后从桌面、通知或托盘打开 Orbit 即可停止，不改变任务完成状态。课程与 DDL 保存独立确认状态，课程做题与绝对期限继续有效。播放器优先选取正在响铃的课程，其次选取 DDL；新增提醒不延长已有提醒的期限。

关闭当前响铃后默认保留未来提醒。提示条和持续保留的管理入口可以保留、全部关闭或逐项关闭本次触发任务的后续提醒，列表同时标明普通／强提醒。关闭选择在一个数据库事务中更新并加入同步队列；重建失败保留面板与重试入口。重新打开已完成任务清空关闭记录，编辑页也可手动恢复。

课表日期栏保持原有 58dp 高度、文字大小与布局，点击范围从 DDL 文字扩展至整个日期格子；包含强提醒配置时 DDL 粗体。列表、详情使用现有铃铛图标，详情说明打开软件即可停止，完成状态独立显示。按压反馈覆盖日期格子，边缘点击不跨入相邻日期。大字体详情内容可滚动。

设置 → 课表 → 日期导航／Navigation 增加两个独立的页面隐藏开关。隐藏只移除手机底栏与桌面侧栏入口。内部导航保留 AppTab 标识；隐藏当前页面会返回课表，直接导入与通知跳转可打开带返回按钮的独立页面。

## 数据兼容

- SQLite v11 新增 DDL 的 `strong_reminder_enabled`、`strong_lead_minutes`、`disabled_reminder_lead_minutes`。旧记录默认普通、没有关闭记录。
- JSON 备份仍为 v9，包含可选字段。恢复验证提前时间必须属于任务配置；旧备份继续兼容。
- 显示设置增加 `hideUpcomingPage`、`hideImportPage`，默认 false，同步类别为 display。
- Android 独立原生数据库保存 DDL 提醒实例和待管理回执；Windows strong.json 的 deadlineSessions／deadlineEvents 与课程 session 分离。确认回执处理后仍保留实例标识，防止同一个实例重复响铃；历史实例保留七天。后台／隐藏窗口不视为打开软件。
- 服务端保留旧客户端提交中缺失的三个 DDL 字段与两项显示设置。先部署兼容服务端，再发布客户端；客户端构建不会部署云端。

## 课程强提醒混合模式与答题配置

课程强提醒新增混合模式，每轮独立以 50% 概率选择心算或顺序数字，不保证一次任务同时出现两种题型。心算、顺序数字和混合模式分别保存轮数（1–10，默认 2）；顺序数字数量为 4–25，默认 6，每轮独立打乱位置。

心算简单难度保持两位数与个位数加减；中等为两位数加减或两位数乘个位数；困难为三位数加减或两位数乘两位数。新旧缺失配置均默认中等，答案默认为手动输入，也可使用三选一或六选一。减法交换操作数避免负数，候选答案唯一并且仅包含一个正确答案；手动输入支持四位数答案。

Android 与 Windows 原生生成并验证整组任务，持久化 `tasks`、`taskIndex` 与 `taskProgress`。答错、页面轮询、重新进入和超时重试不会重新生成题目、选项或数字位置，也不延长原有倒计时。旧版本尚未结束的原生会话继续使用原来的题目和六数字规则。DDL 强提醒仍只需打开 Orbit 确认。

设置新增 `mixedRounds`、`sequenceNumberCount`、`arithmeticDifficulty`、`arithmeticAnswerMode`，全局设置与规则独立覆盖均纳入已有设置同步和 JSON v9 备份，无需升级 SQLite。云端和客户端合并时保留旧客户端缺失的新增配置。兼容云函数需先部署；本地构建不会部署云端。

Flutter 静态分析无问题，全量测试 580 项通过，1 项需显式启用的系统通知测试跳过；Android 原生 45 项、云端 32 项通过，Windows 原生自测返回 0。新增三张视觉基线已检查实际字体，覆盖混合配置、25 数字与六选一。Android 真机声音、锁屏以及 Windows 实际托盘提醒仍需人工验收。
