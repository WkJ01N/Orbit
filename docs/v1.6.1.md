# v1.6.1 实现与验收

源码版本 1.6.1+31；SQLite 保持 v11，完整备份升级到 v12。主程序与独立资源组件随 v1.6.1 发布；以下记录本地实现和验收范围。

## 动画与长列表

卡片采用 480ms 的 easeOutQuint，无超调；随机错峰 140ms，总卡片时钟 620ms。
切页保留平移与淡出，移除整页微缩放。接下来页面按数据引用、日期和语言缓存分组／扁平项，
返回时保留滚动位置，进入刷新延后至 260ms 切页动画之后，并合并进行中的刷新。
隐藏或后台页面暂停显示计时。课程列表、DDL 批量记录达到 200 条时在独立 isolate 解析，
数据库句柄、平台通道和 provider 不进入工作 isolate。

隐藏页面保留 Element 状态并暂停布局。未变化 DDL 的刷新不重建课程网格，
课表几何按数据、日期、窗口与显示设置缓存，修改课程和调整窗口仍正常失效。

2026-10-17 Windows Profile，同设备、固定模拟数据、每种规模 20 次切页：

- 200 条课程：UI 最慢帧 27.757ms → 10.438ms；优化后 UI P95 0.433ms、Raster P95 0.743ms。
- 1,000 条课程：UI 最慢帧 66.690ms → 9.804ms；优化后 UI P95 0.440ms、Raster P95 0.763ms。
- 5,000 条课程：UI 最慢帧 261.349ms → 11.385ms；优化后 UI P95 0.427ms、Raster P95 0.760ms。
- 优化后三组均无超过测试工具固定 16ms 阈值的 UI／Raster 帧；该计数不是实际丢帧率，高刷及 Android 真机需按设备刷新率另验收。
- 此组使用预建课程模型，不等同于数据库磁盘延迟；另有启用记录解析 worker 的 Profile 场景。

启用 `ORBIT_PROFILE_ROWS=true`、每次刷新重新解码记录的补充场景也通过。
200／1,000／5,000 条的 UI 最慢帧分别为 14.712／16.609／19.097ms；
固定 16ms 阈值下 UI 超预算计数为 0／1／1，Raster 均为 0。
该场景包含解析和新列表生成的开销，仍不代表真实数据库磁盘延迟；没有据此声称所有场景零掉帧。

采样脚本：`integration_test/tab_switch_performance_test.dart`，通过 `ORBIT_PROFILE_ROWS=true`
启用大批记录解析。完整原始结果保存在本机 `.dart_tool/v161-tab-*.json`，不含用户数据。

## 按需组件

默认主包保留系统字体支持、Nunito、轻量纹理/JNI 桥接及许可文本。
资源圆体、粉圆、麦圆和视频原生库位于 `resources/` 与原生构建输入中，不随主包嵌入。
资源管理可查看下载大小和安装后占用，支持取消、重试、删除、旧缓存清理及非当前架构组件删除。
下载的临时压缩包在安装完成后清理；导入字体和用户背景文件不属于组件缓存。

`ComponentDescriptor` 包含固定版本、平台／进程 ABI、最低 build、runtime API、归档 SHA-256、
文件大小和逐文件 SHA-256；目录随主包打包，运行时不接受服务器任意指定的代码模块。
组件使用 `.orbitpack`，避免旧更新客户端误认安装包。下载可用既有官方／镜像来源，
先验证归档，再在工作 isolate 解压与逐文件校验，最后原子安装；取消不提交半成品。
资源存放私有 `components/`，真正使用前再次验证内容，不在默认启动时等待网络。

Android 以 `Process.is64Bit` 和实际进程 ABI 选择库，主包只保留 helper/JNI 和纹理桥接，
加载前将已校验库设为只读。Windows 默认插件为无媒体依赖的入口，加载器在完整组件就绪后
注册独立渲染 DLL。已加载原生组件保持到进程结束，删除需下次启动生效。

项目内固定版本适配见 `third_party/ORBIT_ADAPTATIONS.md`。用户的全局 Pub 缓存不做修改。
字体、视频依赖保留许可及来源；应用许可页也可查看文本。图片、GIF 和提醒音频不依赖视频组件。

本机已验证：缺少运行库可正常启动；Windows 安装经校验组件后可实际解码视频，静音且禁用音轨，
图片／GIF／视频跨标签与搜索、账号页面过渡通过。Android 的实际加载、硬件解码及前后台恢复仍待设备验收。

## 备份与版本管理

v12 包含两套字体选择、正在使用的导入字体和已下载字体组件的版本化文件数据；
缺少可下载字体时保留期望选择，使用有效默认字体并提示下载。
降级保护额外保存未使用的导入字体和本机启动图标／入场设置。字体备份仍有总量限制，
超限或资源缺失将阻止降级继续，避免生成不完整保护包。
视频可执行库不进入数据备份，恢复后根据当前平台重新下载。仅恢复课程不改变字体或组件。

更新页支持同版重装、兼容架构选择和历史分页。新增只读云代理 `/v1/updates/releases`
及 `/v1/updates/releases/vX.Y.Z`，仍可回退官方 GitHub；代理代码本次没有部署到生产。
旧客户端的 `/v1/updates/latest` 与应用更新清单 schema 1 保持兼容。

降级兼容矩阵：v1.5.5 → JSON v9；v1.5.6–1.5.7 → v10；v1.6.0 → v11；v1.6.1 → v12。
转换按目标能力删除字体、背景和显示选项，列出具体损失及数量，保留原始保护备份。
转换结果由冻结的历史备份／设置解析器回归验证；未知版本不承诺恢复，缺少官方校验信息时转到官方发布页查看。

保护 ZIP 包含 current-protection.orbit、目标兼容 JSON/.orbit、目标安装包及 README。
必须选取应用外位置并完成导出回读校验，才能显示后续手动降级步骤。Android 不绕过系统
versionCode 限制、不自动卸载；Windows 不直接改写或降低现有数据库版本。
用户先解压保护包，再退出／卸载、安装旧版及导入兼容文件；账户需重新登录，云同步不替代备份。

## WeMust 与设备边界

Android 设置 → 调试 → WeMust 可测试候选课表链接和普通启动，显示安装版本、固定包名、
候选 URI、时间及返回结果，并可复制诊断。Windows 不显示入口。
诊断不包含账号密码；不添加自动填写、自动登录、无障碍导航或内置打卡。
Intent 成功只说明系统启动目标应用，实际页面落点仍需真机确认。

## 构建和发布准备

1. `flutter build windows --release` 构建独立视频后端。
2. `python tool/collect_video_runtime.py` 收集 Windows DLL；`python tool/build_components.py` 同时生成全部组件与主包目录。Android 上游 JAR 使用固定 SHA-256 校验。
3. 在同一份组件目录下构建 Android 通用／各架构和 Windows 主包，再生成安装包清单；不要只发布主程序而遗漏组件。
4. Release 工作流先构建后端，由一个任务统一生成组件，避免跨操作系统压缩实现差异造成目录与实际文件不一致。所有平台使用同一目录后再编译。
5. 本地验收包位于 `release/v1.6.1/`；组件在其中的 `components/`。更新清单与组件校验清单分开，保留旧客户端通用 APK 排序。

发布前需要将组件附件与主包一同上传，并部署新增的只读历史版本代理；线上下载地址在 v1.6.1 正式发布后生效。
本次没有覆盖远程 v1.6.0 标签、发布附件或生产云函数。
