# Orbit v1.6.4 实现与验收

版本 `1.6.4+34`。本记录描述本地实现、验收及构建结果；正式安装包由标签 `v1.6.4` 的 Release 流水线构建，发布入口为 [v1.6.4](https://github.com/WkJ01N/Orbit/releases/tag/v1.6.4)。保留无关文件状态，已有的 `release/v1.5.4/RELEASE_NOTES.md` 删除不包含在版本提交中。

## 拉伸与退出的衔接

- 设置分类单独启用 `RetainedPageSwitcher.keepOutgoingTickers`；默认值仍为 false，其他页面生命周期保持原逻辑。模块入场继续暂停自身进度，旧分类的原生拉伸弹簧则在外层淡出期间持续运行，完全隐藏后停用时钟。
- 每个缓存分类持有独立滚动控制器、指针集合和稳定绘制边界。退出时取消旧指针，帧末终止滚动活动并保持当前滚动位置，以滚动结束通知启动原生回弹；不先清除拉伸，也不等待回弹完成再切页。
- 清理回调使用会话编号校验，快速返回时失效，不会停止重新激活分类的新操作。滚动内容和边缘滤镜保留在同一缓存子树中，不使用异步截图。
- 分类布局准备阶段仅在真正新入场时隐藏整页；重新激活仍可见的分类时保留现有绘制，修正反向切换出现的一帧空白。
- 缓存层在初始化时建立，避免关闭动画／减少动态效果绕过透明度读取后，延迟初始化误用新分类索引。

## 验证方法

- 新增 20 项回归：真实设置页顶部／底部、仍按住／已松手、干净利落及流畅三档速度，共 16 个组合；另覆盖关闭动画、减少动态效果、其他切页器的默认时钟行为及实际合成像素连续性。
- 用例在原生 `StretchEffect` 形变量非零时切换，不在切换前调用 `pumpAndSettle`。验证旧滚动活动结束、形变随帧缩小、滚动位置和页面状态保留，隐藏后时钟停用。
- 对稳定绘制边界进行像素取样，验证第一帧不突然消失、淡出中旧颜色仍参与合成，以及 A→B→A、A→B→C 切换瞬间像素连续、绘制边界复用。
- 临时关闭退出时钟的对照测试在“流畅／顶部／按住”场景失败，恢复修复后通过；对照日志为 `build/v164-overscroll-baseline.log`。
- 更新说明位于 `docs/releases/v1.6.4.md`。历史 v1.6.3 验收记录与产物保持原样。

## 检查结果

- 完整 Flutter 测试：859 项通过，1 项按环境条件跳过。跳过项需要显式启用 Windows 原生通知实测。
- 相关设置、版本及动画回归 33 项通过；最终拉伸与版本回归 21 项通过。
- `flutter analyze --no-pub` 无问题；354 个 Dart 文件格式检查为 0 个变化，`git diff --check` 退出码为 0。
- 当前设备列表只有 Windows、Chrome、Edge，没有连接 Android 实机。Widget 测试覆盖拉伸及绘制连续性；Android 真机 Impeller 着色器路径、双指触摸观感及覆盖升级未完成实机验收，不以自动测试替代。
- 发布前 CI 暴露 Android 提醒诊断记录同毫秒写入的排序不稳定；读取和保留最近 64 条记录时增加 `rowid` 倒序作为次级排序，新增固定同时间戳的原生回归测试，不修改表结构。修复后本地 Android 原生测试 48 项全部通过，日志为 `build/v164-publish-native-tests.log`。

SQLite 保持 v12，完整备份保持 v13。未修改云端协议、包名、签名或字体持久目录。
