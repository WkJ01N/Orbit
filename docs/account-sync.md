# 账号与课表同步

Orbit 的账号是可选功能。不登录时课程、导入、提醒和备份继续在本机运行，不会因为网络或云端服务不可用而停止。

登录并确认首次合并后，Orbit 同步以下内容：

- 课程课次及其备注、系列标识；
- 自定义课表识别模板；
- 学期方案和作息方案。

主题、窗口设置、通知权限、提醒开关、系统闹钟状态和自定义提示音不会同步。登录令牌和设备同步状态不会写入 Orbit JSON 备份。

邮箱账号密码为 8–20 位，必须同时包含字母和数字。注册时可以填写 1–24 个字符的显示名称，
也可以登录后点击账号资料再修改。头像支持 JPG、PNG 和 WebP，最大 2 MiB，作为当前用户的
私有文件上传；应用显示时才获取临时下载地址。

注册验证码和重置密码验证码均可重新发送，每次发送后需等待 60 秒。账号、验证码和重置
密码弹窗只能使用明确的取消按钮关闭，误触窗口外部不会清空已经输入的内容。

## 首次合并

第一次在设备上登录时，Orbit 会读取本机和云端摘要，展示本机独有、云端独有、完全相同和冲突数量。发生冲突时，必须逐项选择本机或云端版本；确认前不会修改课表。不同账号登录到保留有课表的设备时也会执行这一流程，不会自动把上一账号的数据上传到新账号。

## 离线与冲突

本地数据库始终是界面的数据源。修改课表后会先在同一数据库事务中保存课程和待上传记录；用户可分别选择在应用启动、回到前台、本地修改后、允许的网络恢复时自动联网，也可随时点击“立即同步”。网络条件支持任意网络或仅 Wi-Fi／有线网络，设置按设备独立保存并包含在完整手动备份中。网络失败不会影响本机课表和已经排定的提醒。

本地修改会合并等待 2 秒；同步期间出现的新修改只追加一次后续同步，避免重复并发请求。云端内容写回本机时暂停本地变化触发，防止形成同步循环。

上传和增量下载在一次云函数请求中完成，服务端将一批修改合并到更少的数据库事务中，以降低
移动网络延迟。只有没有本地修改时才单独请求下载。

两台离线设备修改同一项时，服务端拒绝过期版本并保留冲突。本机与云端版本都会显示在冲突页，用户作出选择后才继续上传。删除与编辑也按冲突处理，不使用无提示的最后写入覆盖。

## 退出与注销

退出账号默认保留本机课表和提醒，只停止联网同步。退出期间的本地修改仍会记录在设备上；再次登录同一账号时会进入首次合并预览。注销账号需要再次输入密码；Orbit 校验密码后删除账号下的云端课表数据，再注销认证账号。本机课表默认保留并解除云端关联。

邀请测试使用独立的腾讯云 CloudBase 环境。正式开放注册前，需要提供实际运营者、联系邮箱、隐私政策地址和数据保留期限。
