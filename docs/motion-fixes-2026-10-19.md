# 页面动画与课程快捷栏修复验收

本轮修复继续使用 `1.6.3+33`。本地验收完成后，按用户要求更新 `v1.6.3` 标签并重新发布同名 Release；正式安装包及组件由发布工作流重新构建，下载校验以 Release 附带的清单为准。

## 行为

- 周切换、日期选择和课程定位只播放日期导航过渡，相邻周预览直接显示；课程数据变更继续使用增删改动画。
- 切回课表使用独立相对时间轴，在导航约一半时从零启动。工具栏、日期栏、时间轴、图标及分隔线有完整的模块入场；卡片约延后 60ms 开始，与框架重叠播放。
- 主页面、设置分类和二级页面遵循左右导航方向；课表切页卡片也使用相应横向滑入，冷启动保留原方向设置。
- 连续切页保留各可见层当前透明度和位置，不强制完成旧动画。异步出现的模块不重置已播放模块；滚动后的列表项直接显示。
- 接下来页面的日期图标和文字同步入场；设置分类栏整体入场，设置分组的背景与边框和首项同步，内部各行独立错峰。
- 快捷栏放在课表局部图层，后续表单始终位于上方。松手后卡片副本与边缘光淡出，选中按钮保留到操作路由实际退场完成，其余按钮收回。
- 角落按钮按整体布局预留间距，高亮放大后仍保留至少 12dp。命中区域与发光区域同步更新；取消、切页、后台及布局变化清理残留。

## 兼容与回归

版本、SQLite、备份格式及云端协议不变。新增的导航会话、方向和局部时钟均为内部接口。

新增回归覆盖：导航半程的课表框架首帧、卡片横向方向、周导航不重播、快速反向及连续跨页、设置分类独立时钟、外框与首项同步、异步模块不回跳、快捷栏位于操作页下方、路由退场后再收回及角落高亮后的实际按钮间距。既有课表及设置视觉基线保持不变。

## 最终验证

- `flutter analyze --no-pub`：无问题；Dart 格式检查与 `git diff --check` 通过。
- 完整 Flutter 测试：817 项通过，1 项按环境条件跳过；跳过项为需显式开启的 Windows 原生通知实测。
- 快捷栏截图及交互测试：24 项通过；人工复核编辑表单在浮层上方、角落按钮高亮后的间距及柔和发光。
- 课表、主题与设置的既有视觉基线无需更新。回归同时覆盖无课程、空周和加载／错误状态。
- Windows Profile 的 200／1000／5000 条隔离数据场景通过。平均构建帧为 0.847／0.868／0.834ms，99 百分位为 4.149／3.152／3.137ms；最慢构建帧为 26.332／27.129／23.073ms，分别有 20／20／19 个构建帧超出预算。200 条场景另有 2 个栅格帧超出预算，1000／5000 条场景无栅格超时。少量切换帧仍存在尖峰，不能据此宣称所有帧均达到预算。
- 可用设备为 Windows、Chrome 和 Edge，未连接 Android 实机；Android 平台手势由自动测试覆盖，真实连续触摸及动画观感尚未完成实机验收，Windows 性能结果不代表手机帧率。

模块复用独立合成层和页面主题；入场排序复用单批次坐标，相邻周不参与扫描，避免反复重绘整页。临时性能定位代码已移除。
