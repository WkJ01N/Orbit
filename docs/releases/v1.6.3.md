# Orbit v1.6.3

版本：1.6.3，构建号：33。首次发布：2026-10-18；修复重发：2026-10-19。

## 本次重发修复

- 切周、选日期及定位课程不再触发课表入场；切回课表时，工具栏、日期栏、时间轴和网格线使用独立时间轴，完整播放入场动画。
- 连续切页从当前透明度与位置平滑衔接，取消过期任务；主页面、设置分类、二级页面及课表卡片按切换方向左右浮现。
- 补齐“接下来”的日期图标、设置分类栏及分组背景与边框的动画，异步加载不会让已出现的模块重新隐藏。
- 课程快捷栏改为课表局部浮层，松手后卡片副本和边缘光淡出，编辑、备注及确认表单正常显示；角落按钮放大后仍保留间距。

本次重发保持版本名称及构建号不变。已安装同版本时，可从本 Release 下载对应安装包覆盖安装。

## 更新

- 简化替补字体入口说明，修正详情中日期、时间、地点、教师等文字与图标的对齐。
- 学期归属整合进编辑，创建单节、批量课程和考试时均可选择或填写学期。
- 课程选择中的已结束课程默认收起，统一置于底部“查看已结束课程”。
- 主页面和二级页面改为模块错峰入场，在页面过渡约一半时开始，修复先显示再消失的问题。
- 课表刷新保留完整画面，增加课程／DDL 的新增、删除和修改动画。
- 手机新增默认开启的课程快捷栏，支持滑动选功能、方向调整、边缘合并、分段发光及向内悬浮；可关闭恢复原交互。
- 手机设置分类指示条连续滑动，快速切换保持衔接。
- 长列表保留懒加载，课程与 DDL 分开缓存，减少刷新时的重复分组。

SQLite 保持 v12，完整备份保持 v13。保留既有动画偏好，快捷栏设置随完整备份迁移，不参与云同步；无需升级云端 API。

## 验证

- `flutter analyze --no-pub`：无问题。
- `flutter test --no-pub --reporter expanded`：817 项通过，1 项按环境条件跳过。跳过项为需显式启用 `ORBIT_NATIVE_REMINDER_SMOKE=1` 的 Windows 原生通知实测。
- 快捷栏截图与交互专项：24 项通过。人工复核编辑表单位于浮层上方、角落按钮间距及柔和发光；既有课表与设置视觉基线无需更新。
- Windows Profile 的 200／1000／5000 条隔离数据切页测试通过，明确开启切页入场。三组平均构建帧分别为 0.847／0.868／0.834ms，99 百分位为 4.149／3.152／3.137ms；最慢构建帧为 26.332／27.129／23.073ms，分别有 20／20／19 个构建帧超出预算。200 条场景有 2 个栅格帧超出预算，1000／5000 条场景无栅格超时；少量切换帧仍有尖峰。
- 快捷栏自动测试使用 Android 平台手势配置，覆盖出现过程中滑动、取消及悬浮不动手指。可用运行设备为 Windows、Chrome、Edge；未连接 Android 实机，连续触摸与动画观感尚未实机验收，Windows 性能结果不代表手机帧率。

性能原始报告：`build/tab-switch-profile.json`。本次修复的构建、静态检查和完整测试日志保存在 `build/motion-fix-*.log`。
