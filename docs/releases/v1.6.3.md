# Orbit v1.6.3

版本：1.6.3，构建号：33。日期：2026-10-18。

## 更新

- 简化替补字体入口说明，修正详情中日期、时间、地点、教师等文字与图标的对齐。
- 学期归属整合进编辑，创建单节、批量课程和考试时均可选择或填写学期。
- 课程选择中的已结束课程默认收起，统一置于底部“查看已结束课程”。
- 主页面和二级页面改为模块错峰入场，在页面过渡约一半时开始，修复先显示再消失的问题。
- 课表刷新保留完整画面，增加课程／DDL 的新增、删除和修改动画。
- 手机新增默认开启的课程快捷栏，支持滑动选功能、方向调整、边缘合并、分段发光及向内悬浮；可关闭恢复原交互。
- 手机设置分类指示条连续滑动，快速切换保持衔接。
- 长列表保留懒加载，课程与 DDL 分开缓存，减少刷新时的重复分组。

SQLite 保持 v12，完整备份保持 v13。保留既有动画偏好，快捷栏设置随完整备份迁移，不参与云同步；无需升级云端 API。

## 验证

- `flutter analyze --no-pub`：无问题。
- `flutter test --no-pub --reporter expanded`：809 项通过，1 项按环境条件跳过。跳过项为需显式启用 `ORBIT_NATIVE_REMINDER_SMOKE=1` 的 Windows 原生通知实测。
- 课表与界面视觉专项：60 项通过。人工核对深浅主题详情，以及课程快捷栏、向内悬浮和功能位置设置截图；课表网格及渐变保留既有视觉基线。
- Windows Profile 的 200／1000／5000 条隔离数据切页测试通过，明确开启切页入场。三组平均构建帧分别为 0.489／1.037／1.036ms，最慢构建帧为 14.687／14.880／15.624ms，均无构建帧超出预算。200 条场景有 1 个栅格帧超出预算（18.686ms）；1000／5000 条场景无栅格超时。
- 快捷栏自动测试使用 Android 平台手势配置，覆盖出现过程中滑动、取消及悬浮不动手指。可用运行设备为 Windows、Chrome、Edge；未连接 Android 实机，连续触摸与动画观感尚未实机验收，Windows 性能结果不代表手机帧率。

性能原始报告：`build/tab-switch-profile.json`。构建日志、静态检查和完整测试日志保存在 `build/v163-*.log`。
