# Orbit v1.7.0

版本：1.7.0，构建号：36。

- Android 新增原生桌面微件（AppWidget）：
  - 提供「下一节课」紧凑卡片（默认 4×1，支持缩放至 2×2 / 4×2）与「今日课表」可滚动列表（默认 4×3，支持 4×2–4×4），通过只读 WAL 数据库直接渲染，不冷启动 Flutter。
  - 支持在微件内开启近期未完成 DDL（含逾期提示、仅今天 / 近 3 天 / 近 7 天窗口），跟随当前主题色、课程多彩配色与深浅色模式，并可在「设置 → 外观 → 桌面微件」调整背景不透明度（35%–100%）与一键添加到桌面。
  - 课表与设置变更即时防抖同步，上下课及跨日节点通过非唤醒 RTC 广播自动切换状态，点击具体课程或 DDL 直达应用内详情弹窗。
- WeMust 打卡入口窗口优化：Android 点击打卡通知直达 WeMust 课表，普通课程详情在开课前 30 分钟至开课后 30 分钟内显示“打开 WeMust 课表”。
- 账号会话与统计归属稳定性修复：
  - 仅在明确会话无效（401）时才清除本地凭据，5xx / 限流 / 异常响应 / TLS 与读写出错均保留登录态；串行化客户端 Session 读写，云端为旧 Access / Refresh Token 提供重试宽限窗口。
  - 解耦 `bound_account_uid` 与登录态统计归属，阻止退登状态下 `guest` 抢占原账号课程及误标 `withdrawn` 污染云端。
- 提醒可靠性与跨进程并发加固：
  - Android 提醒新增原生批量调度通道与 300 活跃闹钟滚动窗口（由 6 小时维护任务滚动补齐），消除主线程卡顿与系统上限丢提醒风险。
  - 主进程 Flutter 与 `:reminders` 原生进程共享数据库统一启用 SQLite WAL 与 `busy_timeout = 5000`，收窄 `OrbitReminderLedger` 写锁区间并将结构校验收敛至 SQLite v13 升级。
- 性能、导出、架构与云端治理：
  - 拆分 `deadlinesRefreshProvider` 隔离 DDL 与课表刷新，去除了根节点冗余重建；为 `AppDatabase` 补充复合局部索引并将自动归档、学期与课程系列查询下推至 SQLite。
  - `.ics` 日历导出增加 `VALARM` 提醒与活跃 DDL 事件；`ReminderSettings` 改为单键原子落盘（兼容旧版 17 键平滑迁移），清理遗留旧闹钟死代码与冗余开机广播，并将 `AppDatabase` 与 `GridWeekView` 拆分为领域子模块。
  - CloudBase 后端新增策略按需惰性读取、版本发布 404 负缓存及 14 天过期同步幂等回执自动清理（需重新部署 `cloudbase/functions/` 后生效）。

保留 Android 包名与签名；SQLite 升级至 v13（兼容旧版迁移）。

提供 Android 通用版、三种架构安装包及 Windows x64 版。Android 用户可直接覆盖安装以保留数据。

本地验证：静态检查通过（0 issues）；全仓 `dart format` 375 个文件无差异；完整 Flutter 测试 925 项通过、1 项按环境条件跳过（另有 2 项 `deadline_strong_visual_test.dart` 截图基线存在既有本机渲染像素差异）；Android 原生单元测试 57 项通过；CloudBase 云函数测试 42 项通过。真机桌面微件缩放与跨节切换效果待打包验收。
