# Orbit v1.6.1 更新内容

内部构建号：31。

## 动画与性能

- 柔化课程卡片与当前时间线的入场收尾，保留无回弹、上下交错和快速完成的节奏。
- 优化大量课程下“接下来”切页：缓存分组和列表数据，延后进入刷新，暂停隐藏页面显示计时，减少隐藏课表布局与无变化 DDL 刷新造成的重复计算。
- 保留滚动位置、惰性卡片构建、减少动画和快速切页操作。

## 精简主包与资源下载

- 默认保留系统字体和 Nunito。资源圆体、粉圆、麦圆改为按需下载，预览确认后使用，下载后可离线使用。
- 视频背景播放库改为可下载组件。缺少组件时保留设置并显示已有封面，图片、GIF 和提醒继续独立工作。
- 新增资源管理：进度、取消、重试、大小、删除和旧缓存清理。视频库按进程架构选择，加载中的组件删除在重启后生效。
- 组件来自固定官方版本，检查大小、SHA-256、文件清单及兼容信息，随包保留许可和来源。

## 版本选择与降级保护

- 已是最新版时仍可重新下载安装；支持兼容架构选择和历史稳定版列表。
- 安装前检查 Android 包名、签名、版本与架构。旧版安装提供保护包及手动重装指引，不绕过系统降级限制。
- 降级前必须成功保存并回读校验保护包，其中包含原始备份、目标兼容备份、安装包及操作说明。
- 为 v1.5.5 及以后已验证版本提供兼容转换，展示无法恢复的内容；更早版本标为未适配，缺少校验信息时仅提供官方发布页。
- 完整备份升级至 v12，支持下载字体的离线迁移；降级保护额外保存导入字体库和本机启动资源。兼容 v1–11 导入。

## WeMust 调试

- Android 设置 → 调试新增 WeMust 课表跳转和普通启动测试，显示版本与诊断信息。
- 系统接受链接不等于已到课表或已打卡；实际落点仍需真机确认。本版没有新增自动登录或内置打卡。

## 验证范围

- 静态检查通过；Flutter 回归 757 项通过、1 项跳过；Android 原生回归 47 项通过。
- Android 通用及三种架构 APK、Windows Release 均已本地构建和校验。
- 对比 v1.6.0：arm64 主包 59.50 → 26.63MiB，Windows ZIP 56.90 → 16.81MiB；可选资源下载后另计。
- Windows Profile 已验证长列表切页和独立视频组件播放。Android 真机的动画观感、动态视频加载和 WeMust 实际页面落点仍待验收。
- 字体及视频组件随本版本提供，按需下载后可离线使用。新增历史版本云代理尚未部署，客户端可回退官方 GitHub 获取。完整记录见 [实施与验收](https://github.com/WkJ01N/Orbit/blob/v1.6.1/docs/v1.6.1.md)。
