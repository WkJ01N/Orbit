# Orbit v1.6.4

版本：1.6.4，构建号：34。

- 修复设置页在顶部／底部仍处于拉伸或回弹状态时切换分类，旧分类退出动画突然消失的问题。旧内容会从当前形变继续回弹，同时淡出。
- 修复快速切回仍可见的设置分类时，布局准备阶段错误隐藏整页一帧的问题；保留滚动位置及当前动画进度。
- 修复关闭动画或启用系统减少动态效果时，首次切换可能未加入目标分类的问题。
- 优化页面过渡：干净利落风格增加淡入，流畅风格提供三档速度，补齐设置内容及二级页入场，修复返回动画衔接、动效开关闪烁及内容消失。
- 下拉选周和回到今日时，目标课程与当前时间线共用滑入；左右滑动、箭头及课程定位不重播入场。
- 保留下载及导入字体与字体选择，兼容旧组件目录和完整备份。

保留 Android 包名和签名；SQLite v12、完整备份 v13 及云端协议不变。

提供 Android 通用版、三种架构安装包及 Windows x64 版。Android 用户可直接覆盖安装以保留数据。

本地静态检查通过，完整 Flutter 测试 859 项通过、1 项按环境条件跳过。Android 实机拉伸渲染与覆盖升级尚未完成实测，详细范围见 [v1.6.4 实现与验收](https://github.com/WkJ01N/Orbit/blob/v1.6.4/docs/v1.6.4.md)。
