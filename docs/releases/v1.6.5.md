# Orbit v1.6.5

版本：1.6.5，构建号：35。

- 新增 iCalendar（.ics）导出。设置 → 数据管理 里的「导出日历 (.ics)」把当学期课程写成 RFC 5545 日历，可交给系统日历或其他日历应用打开；时间按 UTC 绝对时刻写入，不依赖设备时区。
- 课表网格支持键盘操作：方向键在同一天的课程间向上／向下移动，Enter 打开课程详情，Esc 取消选中。翻页仍是左右方向键。
- Android：应用未打开期间错过的 DDL 强提醒会在 24 小时内补发一次。DDL 提醒现在与自定义规则一样写入本地投递账本，已响过的不会再补。
- 同步冲突保留历史。冲突页右上角可打开历史列表，逐条查看被覆盖的本地修改、发生时间与是否已处理；历史不会在解决冲突后消失。
- 新增应用内隐私政策页，登录页注册前即可进入，说明收集范围、存储位置、不使用的第三方能力、保留期限与删除方式，并标注当前同步运行在 beta 环境。
- 修复跨夏令时切换时「明日课程」摘要落到错误日期的问题（改为按日历日加减，不再用 24 小时步进）。
- 修复通知栏残留的同一 notification id 通知会吞掉后续提醒的问题：只有标题与正文都与待发提醒一致时，才视为已送达。
- 修复提醒列表在 Windows 上超过上限被截断时无任何记录的问题：截断条数会写日志并随调度报告返回。
- 修复新开启的同步分类因「已应用选择」求交集而永不生效的问题；首次合并确认后再次调整分类也会正常同步。

保留 Android 包名与签名；SQLite v12、完整备份 v13 及云端协议不变。

提供 Android 通用版、三种架构安装包及 Windows x64 版。Android 用户可直接覆盖安装以保留数据。

本地静态检查通过，完整 Flutter 测试 895 项通过、1 项按环境条件跳过。Android 实机上的补发投递与强提醒响铃、以及用系统日历打开 .ics 的效果尚未实测。
