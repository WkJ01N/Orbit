# Orbit v1.6.2

版本：1.6.2，构建号：32。日期：2026-10-18。

## 更新

- 添加考试，可关联课程或独立创建，手动设置时间地点；默认提前 30 分钟强提醒，结束后自动计入考试统计。
- 统计首页仅展示最近学完的 5 门课程，查看全部进入懒加载列表。
- 自动识别学期，提供全部学期、本学期及具体学期筛选，并支持校正名称、日期和归属。
- 修复课程／考试详情的图标与文字对齐，适配多种字体及文字缩放。
- 新增最多三种替补字体、数字优先级和拖动排序；无中文字形字体导入后引导配置，最终回退系统字体。
- 分开控制品牌动画、四个主页面入场和播放时机；默认仅启动触发，切页和回前台默认关闭。

SQLite 升级至 v12，备份升级至 v13。原生 XLSX 附带考试元数据；降级保护包保留完整新数据，兼容包明确排除旧版本不支持的内容。

## 验证

- Flutter 完整回归：780 项通过，1 项跳过（需主动启用的 Windows 原生通知烟测）。
- 最终相关测试：33 项通过；账户同步及考试能力验证：18 项通过。
- 云端 Node 测试：38 项通过（含共享部署代码一致性）。
- 格式检查、静态分析及差异空白检查通过。
- Android 通用 Release、Windows x64 Release 构建成功，版本和构建号均已核对。
- Windows 原生强提醒自检退出码 0，APK 发布签名验证通过。
- 详情页深浅主题截图已检查并更新基准。

## 发布产物

- Android 通用 APK，以及 ARM64、ARMv7、x86_64 专用 APK，版本号和构建号一致。
- Windows x64 ZIP，解压后保留 `data/` 与 DLL。
- 中文字体及视频播放资源组件、组件目录、`update-manifest.json` 和 `SHA256SUMS.txt`。

正式安装包由 GitHub Actions 从 v1.6.2 标签构建，SHA-256 以 Release 附件中的校验清单为准。

## 云端与设备验收

四个线上云函数已先行更新，运行状态均为 Active；重新下载的生产代码与发布源码逐文件哈希一致。同步接口未认证请求返回 401。客户端发送考试前检查服务端能力；旧服务端不接收考试写入，本机数据及待同步队列保留。

Android 真机动画、厂商后台提醒和冷／热启动体验仍待设备验收。Windows 原生自检不代表已完成全部桌面视觉和系统通知场景验收。构建中的 Kotlin 插件迁移提示来自现有依赖，不影响本次构建成功。

实现细节见 [v1.6.2 实现](https://github.com/WkJ01N/Orbit/blob/v1.6.2/docs/v1.6.2.md)。
