# Orbit v1.6.3 实现与验收

版本 `1.6.3+33`。沿用 SQLite v12、完整备份 v13 和现有云端协议。

## 字体、详情和学期

字体设置中的替补字体入口说明改为“当字体缺失时使用替补字体”，繁体中文和英文同步更新；替补字体页面内部继续解释数量、排序和优先级。

详情信息行固定图标位置，按实际文本首行的字体度量向上校正文字。计算包含界面字体、替补字族、语言和系统文字缩放；多行备注对齐首行。深浅主题详情图已人工复核。

详情中的独立学期归属按钮合并到编辑表单。单节课程、批量课程和考试可以选择已有学期、输入新名称或留空按日期推断；选择已有课程时带入归属。已有学期同时包含导入计划、课次和仅存于统计历史中的学期。保存同步处理名称和稳定学期 ID，并按现有范围选择更新课次及统计归属；编辑期间不提前写入。

## 课程选择

共用课程目录按学期身份和课程系列聚合。只有全部未删除课次均已结束时才算整门课程结束；考试不延长普通课程的完成时间，归档状态独立保留。

创建课程、批量课程、考试关联、DDL 科目、提醒和学期分配中的结束课程默认收起，放在选择区域底部的“查看已结束课程”中。展开后继续懒加载，搜索统计历史匹配数量，收起不会清除原有选择。目录按数据和时间更新，打开的选择器在分钟边界重新检查结束状态。

## 页面和课表动画

页面激活时立即准备隐藏状态，跟随真实导航动画在约一半时启动模块入场。页面内容按屏幕从上到下、同排从左到右错峰出现，普通模块约 420ms，错峰总跨度不超过 180ms。二级页面继承所属主页面的设置，弹窗和底部表单保留容器过渡。

保留 v1.6.2 的动画开关和默认触发偏好。减少动态效果、紧急提醒、窗口变化及取消切页会结束或取消过期播放。模块绘制、点击位置和语义坐标使用同一变换；只为当时可见的模块分配入场时序，用户开始操作后新滚入的列表项直接显示。

课表冷启动卡片仍采用 480ms 的滑入和 140ms 内的错峰，起始顺序改为视觉顺序；方向继续遵守边缘／附近设置。数据刷新提交课程和 DDL 的完整显示快照，保留上一份成功结果和视口，不临时替换为骨架或空数据。失败时保留画面并提示错误。

新增课程仅让新增卡片滑入，删除保留卡片快照至淡出完成，编辑交叉淡变。操作结果携带旧、新课次 ID 的映射，时间修改不会被误认成新增。DDL 日期标识和数量变化采用淡变。最后一张卡片与空态之间也有过渡。

入场等待、播放和结束阶段使用稳定的组件结构，保留课表布局缓存、表单和滚动状态。结束后释放入场裁剪，避免截掉分数像素位置的网格线。课次按日期建立复用索引，只对当前与相邻页面的日期执行布局计算；首次自动定位仅执行一次，切页重播不重置手动滚动位置。

“接下来”的课程分组索引与 DDL 前缀分别缓存；DDL 刷新不重新计算全部课程的周标记。列表维持懒加载和滚动位置。

设置分类指示条改为单个连续移动的指示条，快速切换从当前位置重新定向。分类内容与指示条共用选择状态，分类入场的取消代次独立校验，避免过期回调再次启动动画。

## 手机课程快捷栏

设置 → 课表 → 课程快捷栏，默认开启，仅用于手机端课程和考试。关闭后回到原长按选项栏。默认上编辑、右备注、下删除、左归档；选择已占用的方向功能会交换两项。配置保存在本机，完整备份携带，云设置不携带。

四项按上、右、下、左从卡片背后滑出，间隔 35ms，单项 240ms。分区在出现动画中即可命中；高亮和柔和边缘光从当前状态衔接，允许连续打断与反向。卡片内部为取消区，边界有滞回，未选中时松手收回。

普通位置使用四角向外的 45° 射线。左右贴边和上下贴边分别采用参考图的斜向／垂直分区，被阻挡的项移至对侧，对侧双项保持相同目标尺寸和对称的触发划分。角落用 45° 射线分开两个可用方向，每侧近处保留原项，远处为移入项。只照亮选中分区对应的边缘段。

可选“向内悬浮”：卡片以 260ms 移入，适当放大并增加阴影，保留原布局占位。实际手指位移达到 10dp 后才允许选中，防止卡片移动本身造成误触。窄小空间会限制悬浮尺寸。放大的短课程点击区使用同一手势与实际卡片边界。

松手后其他三项同时收回，选中项保留至编辑、备注、归档或删除流程返回。删除沿用范围、统计和确认流程；成功删除或归档隐藏时卡片与残留选项淡出。编辑改变卡片时，返回后原视觉副本与新画面淡变衔接。页面切换、后台、布局改变及系统返回均会清理快捷栏。

## 验证与产物

最终检查、性能结果、构建产物和实机限制见 [v1.6.3 发布说明](releases/v1.6.3.md)。

主要新增测试为 `test/v163_interactions_test.dart` 和 `test/v163_data_motion_test.dart`，覆盖分区、悬浮误触、展开懒加载、运行中结束课程、真实导航半程、动画命中坐标、学期统计事务、设置备份、数据刷新失败及课表增删改动画。

性能场景使用 `integration_test/tab_switch_performance_test.dart` 的 200／1000／5000 条隔离数据，明确启用切页入场；结果写入 `build/tab-switch-profile.json`。测试不连接个人课程数据库，也不更改真实应用的偏好。
