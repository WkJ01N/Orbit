# 课表导入指南

Orbit 在本机识别 XLSX 和 CSV 文件。暂不支持旧版 XLS、PDF、图片、HTML、ICS，也不自动调整节假日和补课日期。

## 导入步骤

1. 在「导入」页选择一个或多个 XLSX / CSV 文件。
2. 勾选要导入的工作表。自动识别会建议课程工作表；没有候选或有多个候选时，请明确选择模板，或点击「字段映射」配置。
3. 对只有星期、周次或节次的课表，点击「确认本次导入的学期、周次与作息」，选择已保存方案，或填写临时参数。只有明确日期与起止时间的列表无需方案。
4. 点击「解析与预览」，检查每张表的模板、课程、日期范围、重复数量和错误位置。此时尚未写入课程。
5. 修正错误后重新预览，或明确勾选「跳过识别失败的课程」。损坏文件、模板不明确、解析超时等无法通过跳过课程解决，可排除相应工作表后重新解析。
6. 确认导入。涉及已有课程周次时，选择整周替换或合并并覆盖冲突；完成后重新排定提醒。

修改模板、工作表选择、编码、分隔符或学期参数，会清除旧预览和跳过确认。取消、测试及预览均不写入课程库。完全相同的课次去重；同一课次编号对应不同内容时，两种内容均不导入，必须修正或明确跳过。

## 课程列表

列可重排，也可包含额外列。基础示例：

```csv
课程名称,日期,开始时间,结束时间,教室,教师
高等数学,2026-09-14,08:00,09:40,A101,张老师
大学物理,2026-09-20,10:00,11:40,B202,"李老师,王老师"
```

必需信息为课程名、有效日期及起止时间，或能够展开的星期、周次及节次。支持简繁中文和英文常见表头，例如 `course name`、`date`、`weekday`、`weeks`、`periods`、`start time`、`end time`。

日期支持 `2026-09-14`、`2026/9/14`、`2026年9月14日`；时间支持 `08:00`。星期支持 1–7、周一至周日、星期一至星期日、Monday 至 Sunday。已填写星期时，必须与明确日期一致。

起止时间已经明确时优先使用时间；否则根据节次取首节开始和末节结束。课程编号等其他字段可留空；无编号时自动生成稳定内部编号，教师中的 `null` 会被过滤。

按周列表示例：

```csv
课程名称,星期,周次,节次,教室
高等数学,周一,1-16(单周),1-2,A101
大学物理,周一,1-16(双周),1-2,A101
```

周次支持 `3`、`1-16`、`1,3,5-8`、`1-16(单周)`、`1-16(双周)` 及对应繁体字。周次缺失时，必须在本次导入参数中明确填写适用周次。

## 周网格与一格多课

第一期支持星期为列、节次为行。课程区域可通过原表点击选定；表头、星期列和节次行也可手动调整。纵向合并格根据覆盖的节次计算时间，只读取一次；跨星期列或被课程区域截断的合并格提示错误。

基础网格模板的单元格文字示例：

```text
高等数学
教师：张老师
教室：A101
周次：1-16(单周)

大学物理
教师：李老师
教室：A101
周次：1-16(双周)
```

一门课程中的换行用于教师、教室等字段；课程之间用空行分隔。其他学校样式可自定义课程块分隔正则，或切换为重复匹配。重复匹配规则必须覆盖课程块之间的非空文字，以免遗漏课程。

## 自定义模板与正则

在导入页或「设置 → 数据管理 → 识别模板」创建模板。内置模板只读，可以复制后编辑。

编辑器提供四步：布局与区域、字段映射、提取规则、测试与预览。字段可来自指定列、课程块文字、固定值、网格星期或网格节次。界面中的行列编号从 1 开始；保存后的模板 JSON 内部坐标从 0 开始。

正则直接填写表达式，无需 Dart 字符串引号或外围斜杠。例如：

```text
教师[：:]\s*(?<teacher>[^\r\n]+)
```

将捕获组填写为 `teacher`，即可提取教师；也可使用数字捕获组，例如组 `1`。组 `0` 表示完整匹配。支持区分大小写、多行锚点、点号匹配换行和 Unicode 模式；字段提取使用首个匹配，课程块可使用重复匹配。

在测试页输入示例文字，选择要测试的字段规则或课程块规则，可以查看匹配、捕获组和提取字段。编辑实际文件时，课程展开预览使用该工作表；单独创建列表模板时，课程预览使用示例区的 CSV 内容。

正则测试最多运行 2 秒，每张表解析最多运行 30 秒，可随时取消。超时会终止后台任务并保留配置。

自定义模板可启停、复制、编辑、删除及单独导入导出 JSON。停用仅影响自动识别，仍可手动选择。分享文件仅保存布局、字段映射、固定值和正则，不自动包含课表原文、文件路径、学期或开学日期。导入分享文件前会展示摘要，确认后保存为新模板。

## 学期、作息与备份

方案管理分别保存学期和作息。学期需要名称、第一周的周一日期及 1–30 周的总周数，默认 18 周；作息需要每个节次的真实起止时间。例如：

```text
1,08:00,08:45
2,08:55,09:40
3,10:00,10:45
4,10:55,11:40
```

本次导入参数中的临时修改不会覆盖已保存方案。保存长期方案请使用「学期与作息」管理页；停课和调课通过现有课程管理操作。

完整备份升级为 v5，包含识别模板、学期和作息，即使没有课程也可备份设置。继续恢复 v1–v4；旧备份不包含导入配置时，保留本机已有模板和方案。恢复 v5 设置时，按备份替换导入配置。仅恢复课程时不修改配置。
